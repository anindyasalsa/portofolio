PORTOFOLIO ANINDYA SALSABILA PUTRI — VS CODE

ISI FOLDER
- index.html: struktur dan isi website
- style.css: desain, warna, layout, dan ukuran
- script.js: tombol bahasa Indonesia/Inggris dan perilaku screenshot
- images/projects/: tempat screenshot proyek

CARA MENJALANKAN
1. Ekstrak ZIP ke folder pilihanmu.
2. Buka Visual Studio Code, pilih File > Open Folder, lalu pilih folder anindya-data-analyst-portfolio.
3. Jika belum ada, pasang ekstensi Live Server.
4. Klik kanan index.html > Open with Live Server.

CARA MENAMBAHKAN SCREENSHOT PROYEK
Masukkan screenshot ke folder images/projects dan gunakan nama file berikut (format PNG disarankan):
- retail-sales-analysis.png
- pcos-classification.png
- elderly-health-monitoring.png
- financial-property-app.png
- nutriguide.png
- gofast.png
- cookify.png
- tableau-dashboard.png
- sql-analysis.png

Jika screenshot milikmu JPG/JPEG, ubah ekstensi di nama file dan sesuaikan src pada kartu terkait di index.html. Jangan gunakan screenshot yang memuat data pribadi atau informasi sensitif. Website otomatis mengganti placeholder saat file gambar ditemukan. Untuk hasil terbaik, gunakan screenshot landscape sekitar 1200 x 700 px dan crop agar isi dashboard terlihat jelas.

PERUBAHAN ISI
- Ubah tulisan dan judul di index.html.
- Ubah warna, jarak, dan ukuran di style.css.
- Ubah terjemahan tombol/teks pada object translations di script.js.
- Perbarui tautan email, LinkedIn, dan GitHub di bagian Kontak pada index.html.

Catatan: kartu Tableau dan SQL adalah tempat template sampai kamu memasukkan proyek serta screenshot yang benar-benar kamu buat. Jangan mencantumkan hasil atau angka yang belum diverifikasi.
